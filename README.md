# Blog Web con Django

Proyecto final del curso de Python desarrollado con Django.

La aplicación consiste en un blog web donde los usuarios pueden registrarse, iniciar sesión, crear publicaciones, ver posts, editarlos y eliminarlos.

## Tecnologías utilizadas

- Python
- Django
- HTML
- Bootstrap
- SQLite
- Pillow

## Funcionalidades principales

- Registro de usuarios.
- Inicio y cierre de sesión.
- Diferenciación entre usuarios autenticados y visitantes.
- Listado de publicaciones.
- Vista detallada de cada post.
- Creación de publicaciones.
- Edición de publicaciones.
- Eliminación de publicaciones.
- Carga y visualización de imágenes.
- Rutas protegidas para crear, editar y eliminar posts.
- Solo el autor puede editar o eliminar sus publicaciones.
